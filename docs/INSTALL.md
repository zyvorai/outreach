# Install

1. Download `ZyvorOutreach-0.11.0.dmg` from the [latest release](https://github.com/zyvorai/outreach/releases/latest).
2. Optional: check it against the published hash.
   ```
   shasum -a 256 ZyvorOutreach-0.11.0.dmg
   ```
   The result should equal the line in `ZyvorOutreach-0.11.0.dmg.sha256` on the release page.
3. Open the DMG and drag **Zyvor Outreach** to **Applications**.
4. Launch it. The app is Developer ID signed and notarized, so macOS opens it without a warning.

**Requires** macOS 26 or later.

Your 30-day trial starts the first time you launch. The sidebar shows the days left.
