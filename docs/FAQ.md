# FAQ

**Is this a bulk mailer?** No. It is built for a handful of researched emails a day, with a daily cap, spacing between sends, and a bounce guard.

**Can it send without me looking?** Not by accident. You read the rendered message, and a manual send needs the count typed to confirm.

**What happens when the trial ends?** The app asks for a licence key. Nothing is deleted. See [LICENSING.md](LICENSING.md).

**Do I need a key during the trial?** No.

**What does it run on?** macOS 26 or later.
