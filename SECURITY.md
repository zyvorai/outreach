# Security

Zyvor Outreach is a Mac console for careful, low-volume cold email. It shows what will be sent before anything goes out, sends only after you confirm, and stops on its own when the bounce rate climbs.

Licence keys are verified offline on your Mac. The app does not contact a licensing server.

Report vulnerabilities privately to security@zyvor.dev. Please do not open a public issue for a security problem.

The Zyvor Outreach source code is private.
